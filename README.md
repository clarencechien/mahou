# mahou — 派對遊戲

手機當手把、電視當主畫面的 Kahoot 式派對遊戲。跑在 Cloudflare Workers + Durable Objects 上，**免費方案就能跑**（DO 已設定成 SQLite-backed）。無框架、無 build step，前端全部原生 DOM。

目前有四款可玩的遊戲，以及一整套 Phase 0 的網路量測工具。

| | |
|---|---|
| **一二三木頭人** | 10 回合。綠燈時照大螢幕的指令用手機做對得分，鬼一轉身還在動就倒扣。指令有加減法、選顏色、點幾下、搖手機 |
| **滑雪下坡** | 20–120 秒比距離。連點加速、傾斜轉向、抬起手機跳跳台，連三次解鎖超加速——那是一個**檔位**，連段還在速度就一直停在高檔（真機實測最高 37.9 m/s、27% 的時間在 24 以上）。沒抬手機輾過跳台只是小彈一下，而且 **0.7 秒內補抬還救得回來**。畫面依人數切成 1 / 2 / 2×2 / 4×2 / 4×3，最多 12 人同場 |
| **名畫變色龍** | 3–8 關（可調），畫裡藏會眨眼的小人——**3 隻加到 10 隻**。手機當雷射筆（Wii 式指向，或觸控板）移游標蓋章搶快，DO 用 250ms 結算窗比 client 時間戳。**名畫系八張自己 host 在 repo 裡**（公有領域、挑過小朋友不會怕的），另有**自訂主題**讓主持人用自己電腦上的圖。**每關隨機裁一塊放大**，同一張畫每次都不一樣 |
| **背景模式**（不是遊戲） | `/ambient`。放音樂、跟歌詞、輪播照片。**不用 DO、不開房間**，開著一整場不產生費用。三種尺寸：全螢幕舞台／正下方置中的 widget（**預設**，跟隨模式固定兩行、只顯示一句）／右下角縮小只剩歌名（濃淡拉到 0 就真的只剩歌名）。卡片濃淡可調（`[ ]`，0–1，字不跟著淡；拉到 0 就只剩歌詞浮在照片上）。直式照片不裁，左右留一塊壓成灰的底；貼在白底上的照片會照設定檔裡的 `trim` 切掉白邊。歌詞的日文與中文同級數、各自墊一塊灰（照片全白時白字對比從 1.0:1 拉到 4.5:1）。舞台控制列分成兩層：上層是放的時候會碰的，下層是開場設一次的四組選擇。歌單 1＝家宴原創五首、2＝湖畔家宴兩首、3＝Our Table A/B。歌單與背景都在一個 JSON 裡設定 |
| **砸罐子** | **第一人稱假 3D**，鏡頭不動、飛走的是物件（投影與 Mode 7 地面共用同一組世界座標）。雷射筆瞄哪就打哪：**先按「確定」把準心釘住**（陀螺儀會漂，不釘住球會跑掉），再連點或搖手機蓄力，搖一下＝點兩下的力。**「歡樂度」旋鈕**一次放大打飛力道、朝鏡頭飛的比例、碎片與震動。草捆／木桶／磚牆／鐵桶／炸彈各有 HP 與重量，砸壞什麼算誰的，炸彈連環爆。5 關 |

## 一鍵部署

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/clarencechien/mahou)

按下去 → 登入 Cloudflare → 自動部署。

> ⚠️ **按鈕的陷阱**：Deploy to Cloudflare 會把這個 repo 當模板**複製一份新 repo** 到你的 GitHub 帳號，CI 接在那份複製品上——之後 push 到本 repo 的 main **不會**觸發部署。要持續開發請改用下面的 Import a repository 連本尊，或在 Worker → Settings → Build 把 Git 連動改指回本 repo（自訂網域綁在 worker 上，不受影響）。注意：切完連動要再 push 一次才會觸發第一個新 build。

其他兩種部署方式：

- **Cloudflare Dashboard 連動**（自己開發用這個）：Dashboard → Workers & Pages → Create → Import a repository → 選這個 repo。它會讀 `wrangler.toml` 自動設好 DO binding 與靜態資源，之後 push 即部署。
- **CLI**：`npm install && npx wrangler deploy`（本機開發用 `npx wrangler dev`，但感測器 API 需要 HTTPS，手機實測請直接用部署出來的 `*.workers.dev` 網址）。

## 現場怎麼跑

0. **主控這一台要先登入。** `/host` 在 Cloudflare Access 後面，第一次開會跳到登入頁。
   **只有這一步需要登入**——待會掃 QR 的人一律不用。
1. **電視／筆電**開 `https://<你的網域>/host` → 主控台。按右上角 **⛶**，頂列會在 2.6 秒後自己收起來，畫面只剩遊戲。
   右下角若出現紅色的 **「房間沒上鎖」**，點它一下會說明原因（見「誰可以開房間」）。
2. **手機**掃畫面上的 QR（點一下 QR 可以放大給大家掃）→ 填暱稱（5 字內）→ 加入。
   QR 網址裡帶著房間憑證（`#房號.憑證`），**掃到的人不用登入**，但也因此
   **手抄房號進不去**——晚到的人要掃 QR，不能只報房號。
   **從 LINE 掃到的內建瀏覽器會被擋下並提示改用外部瀏覽器**（感測器權限拿不到）。
3. 頂列選遊戲 → 按 **「開始 ⟨遊戲⟩」**。**不會直接開打**，先出說明卡：
   - 大螢幕顯示規則三條，並念一次解說（事先錄好的旁白，可按「🔊 再念一次」）
   - 同時所有手機切到準備畫面：要感測器權限 → 歸零校準 → **把每個動作試一遍**
   - 說明卡上顯示「N / M 人已就緒」，大家都好了再按 **「開始遊戲」**
4. 玩。要調手感就切到 **測試** 按 **⚙︎ 手感調校**，或直接按 **`T`**（見下）。點面板外面、按 `Esc` 或再按一次都會收起來。
5. 玩完切到 **測試** 按 **「結束房間」** — 會先自動匯出 JSON，再踢掉所有人讓 DO 休眠。
   整晚結束再按一次 **「🚨 關掉所有房間」**，把這台開過的每一間都收乾淨。

### 主控 HUD 的取捨

大螢幕是給**玩家**看的，不是給主持人看的，所以頂列刻意壓到只剩必要的東西：

- 品牌、遊戲選單、**開始**（不帶遊戲名，選單上就寫著了）
- 右邊三顆：**連線燈**（點了才展開右下的 DO 落點浮窗）、**⛶**、**正式／測試**一格開關
- **開打後**頂列只剩品牌＋停止；左下的加入卡縮成一個房號（晚到的人點一下還是能放大 QR）
- 回合標籤精簡成 `3/10`、`2/5`、`1/4・星夜`——倒數就在正中央，不重複寫

調校用的東西（手感面板、Phase 0 探針、匯出、結束房間）全部收在**測試**檢視裡。

**速度倍率會同時放大前進速度與障礙物間距** —— 每秒遇到的障礙物數量不變，但每個物件掃過畫面的時間變短，所以是「變快」而不是「變難」。

調到滿意後按「複製設定」，把數字寫回 `public/host.html` 的 `TUNE_DEF`。

## Phase 0：網路量測

**這一段是「量數字」，不是玩法。** 交付物是一份 JSON。管理・測試分頁保留了完整的探針：

- **② Ping 測試** — 即時 RTT 大字＋紅黃綠燈，主控台看全員一覽
- **③ 單點×10 / 狂點 3 秒** — 上下行延遲分布、掉包率與 seq 斷號
- **④ 搖動計數** — 門檻／遲滯／不應期是畫面上的滑桿，可現場調參。重點是同一人拿不同機器各搖 10 下，比兩邊數出來差多少
- **DO 區域選單** — wnam / apac / weur A/B（hint 只在房間第一次建立時生效，換區域會開新房）。落點結果點主控右上的連線燈就看得到
- **匯出 JSON** — 遙測只存在 DO 記憶體，**房間閒置被回收就沒了，測完立刻匯出**

### 已經量到的數字（台灣，2026-08）

| 項目 | 實測 |
|---|---|
| RTT 地板 | **~150ms**（wifi 與 5G 皆然）—— 由 Cloudflare 入網點決定，不是家用 wifi |
| 滑雪 10Hz 上報的上行延遲 | p50 78–90ms / p95 82–115ms |
| 掉包率 | 0%（狂點 100 次 / 3 秒） |
| 8 人同場 | DO p95 僅 +9ms |
| 對時漂移 | <9ms/100s；網路切換跳 ±27ms 後 10 秒內回穩 |
| 跨螢幕色差 | ΔE<40 玩家分不出 —— **任何判定都不能靠細微色差** |
| 分割渲染 | 捲動雪地 Mode 7 在 1/2/4/8 格都是 4.3–4.4ms（分割數不是成本，總像素才是）；8 格比賽中 p50 16.5ms 維持 60fps |
| 滑雪一場的成績（3.2×、60 秒） | 1310m / 18 座跳台 / 11 連 / 最高 37.9 m/s / 27% 的時間在 24 m/s 以上 |
| 砸罐子上行 | p50 ~82ms；丟球是離散事件，延遲完全無感 |

**三條全平台鐵律**：

1. **判定用 client 時間戳**（`performance.now() + offset`，已對時到伺服器時間軸）。DO 只做排序、去重、廣播，不看封包到達時間。150ms 的傳輸延遲因此不影響任何公平性判定。
2. **本地先回饋**（0ms），網路結果後到再校正。
3. **每個玩家角色頭上都要有名字** —— 任何遊戲、任何視角，沒有例外。大螢幕上一堆同款小人，只靠配色認不出哪個是自己。名牌用 DOM 疊層而不是畫進 canvas（中文在低解析度像素緩衝裡會糊掉）。分割畫面另外要在每格左上角放該玩家的即時狀態。

### DO 落點診斷

**RTT 地板由「Cloudflare 入網點」決定**：

- HiNet 家用寬頻對這個 zone 在 **SJC（美西）入網** → DO 放美西 ~150ms；DO 放香港反而要繞一圈，~360ms
- **中華 5G 在 SIN（新加坡）入網**（`/cdn-cgi/trace` 實測 `loc=TW colo=SIN`）→ 到 HKG DO ~155ms
- 免費方案不進 TPE；治本方向是 zone 升 Pro/Business 再把 DO 切回 apac

所以 `locationHint` 預設 **wnam**（跟著入網點）。診斷工具：`GET /whereami/<房號>` 回 `{doColo, edgeColo}`，主控台點右上的連線燈會展開右下浮窗顯示 DO／邊緣落點，兩個值都要寫進報告。

### 假 client 壓力測試

```bash
node tools/fakeclients.mjs wss://<你的網域>/ws <房號> 8 30
```

8 個假 client 各以 300ms/shake + 100ms/tap 上報 30 秒。兩台實機同場開著，看實機延遲在 8 人負載下的增幅。

### 匯出格式

```jsonc
{
  "roomId": "ABCD",
  "clients": [ { "clientId", "name", "device": { /* ua, screen, motionEventRateHz, ... */ }, "sync" } ],
  "events": [
    // join / syncResult / tap / spamSummary / shake / stage / ready
    // freezeRound / freezeTurn / freezeAct（含 verdict）
    // skiStart（含 seed 與 speedMul）/ skiRun / skiDone / skiEnd
  ]
}
```

所有 client 時間戳都已用 clock offset 換算到伺服器時間軸（offset = t1 − (t0+t2)/2，取 RTT 最小樣本）。

## 計費防呆

這個 POC 用非 hibernation 的 WebSocket，**只要還有分頁連著，DO 就一直佔記憶體計費**；client 又有自動重連＋每 10 秒背景對時，忘記關的分頁會永遠戳著 DO。防呆有三層：

- **閒置自動關房**：30 分鐘沒有真實互動（ping／背景對時不算）→ DO 踢掉所有連線後休眠
- **最長壽命 6 小時**：無條件關房
- **主控台「結束房間」鈕**：先自動匯出 JSON，再踢掉所有人。**每輪玩完建議按這顆**
- **「🚨 關掉所有房間」逃生鈕**：關掉這台瀏覽器開過的**每一個**房間，不用把那些分頁再找回來

被關房的 client 會看到「房間已結束」且不再重連（WS close code 4000/4001）。房間沒有寫任何持久化儲存，所以連線清空後成本歸零。

### 誰可以開房間（＝誰可以花到錢）

預設是**開放**的：任何人打 `/ws/ABCD` 都生得出一個 DO。家宴自己玩沒差，
但網址一旦流出去，路人就能替你開房間然後掛在那裡計費。要鎖起來設兩樣東西。

> ⚠️ **只把 `/host` 放到 Cloudflare Access 後面是擋不住的。**
> DO 不是 `/host` 開出來的，是 `/ws/<房號>` 開出來的——路人不用打開任何頁面，
> 直接連 `wss://…/ws/ABCD` 就生得出 DO。**保護頁面沒有保護到花錢的那條路徑。**
> 所以鎖必須放在 Worker 裡，而且要在 `env.ROOM.get()` **之前**：
> 拿到 stub 就等於生出 DO 了，之後才拒絕已經來不及。

實際的機制是一張 HMAC 簽的**房間憑證**：

1. 主控開 `/host` → 打 `POST /api/room` 換一張憑證（這一步要過 Access）
2. QR 網址帶著它：`/client#<房號>.<憑證>`
3. **掃 QR 的人完全不用登入**，憑證跟著網址走
4. `/ws`、`/export`、`/whereami`、`/close` 沒有有效憑證一律 403，**碰都不碰 DO**

```bash
# ① 房間憑證的簽章金鑰（只有這個就能擋掉「路人直接開房間」）
npx wrangler secret put ROOM_SECRET        # 隨便一串長亂碼

# ② 要求主控本人登入才換得到憑證：先在 Zero Trust → Access controls → Applications
#    開一個 Self-hosted 應用，路徑蓋住 /host 與 /api/room，再把它的兩個識別碼設進來
npx wrangler secret put ACCESS_TEAM        # 團隊名。<這一段>.cloudflareaccess.com，只填前面那段
npx wrangler secret put ACCESS_AUD         # Applications → 該應用 Configure → Additional settings
                                           #   裡的 Application Audience (AUD) Tag，64 位十六進位
```

- 只設 ①：路人開不了房間，但任何人打得開 `/host` 也就換得到憑證。
- ①＋②：只有你登入後換得到憑證，別人連 `/api/room` 都會吃 403。
- 都不設：維持現在的開放行為，而且主控台右下角會出現紅色的
  **「房間沒上鎖」**——寧可醜，也不要讓人以為鎖上了。

**故意不保護的**：`/ambient`（背景模式）、`/audio/*`、`/client` 這一頁本身。
背景模式本來就不碰 DO，鎖它只是找自己麻煩；`/client` 是靜態頁，沒有憑證進不了房間。

> ⚠️ **`workers.dev` 一定要關掉**（`wrangler.toml` 的 `workers_dev = false`）。
> Access 是綁在自訂網域上的，從 `mahou.<帳號>.workers.dev` 進來的請求不經過它——
> 留著等於開一扇沒有鎖的側門，`/host` 誰都打得開，也就換得到房間憑證。

### 沒有主控的房間不會活著

DO 一被回收，房間狀態（含 `ended`）就沒了，所以「已經結束的房間」跟「主控只是
關了網頁的房間」對一個新生的 DO 來說**長得一模一樣**——都是一個空房間。
以前手機只要重新載入那一頁，就會把房間叫回來，然後掛滿 30 分鐘的閒置上限。

現在 `setup()` 在啟動任何東西**之前**先問一句：這個 DO 實例看過主控嗎？
沒有的話直接關掉（`4002 no host`），連看門狗都不開，DO 幾毫秒後就死。

- 主控斷線重連時，DO 被還連著的手機撐著沒被回收 → `hostSeen` 還是 true，**不會誤殺**
- 全部斷光、DO 被回收 → 新實例 `hostSeen` 是 false → 手機重整進來會被擋下
- 手機收到 4002 會退避重試 **6 次（約 24 秒）**，主控回來就自己接上；
  真的散了就顯示「房間還沒開，請重新掃 QR」並停止——不會無限戳

> ⚠️ 這裡有個很容易寫錯的地方：**被拒絕的連線一樣會觸發 `onopen`**，
> 因為 DO 是先接受 WebSocket（101）再關掉它的。退避計數器如果在 `onopen` 歸零，
> 「開了就被關」會變成無限迴圈——實測 42 秒戳了 83 次。
> 所以計數器改成**收到第一則訊息**才歸零（DO 只對接受的連線送 `hello`）。

> Access 的 JWT 是**真的驗簽**的（抓團隊的 JWKS、比對 `aud` 與 `iss`），
> 不是只看 `Cf-Access-Jwt-Assertion` 這個 header 在不在——
> Access 沒有蓋到的路徑，Cloudflare 不會幫你把使用者自己送的同名 header 拿掉。
>
> 兩個值長這樣：
> `ACCESS_TEAM=mycompany`（完整團隊網域是 `mycompany.cloudflareaccess.com`），
> `ACCESS_AUD=4714c1358e65fe4b408ad6d432a5f878f08194bdb4752441fd56faefa9b2b6f2`。
> **AUD 是「每個應用」一組**，不是整個帳號一組——同一個團隊底下開兩個應用會有兩個 AUD，
> 填錯那個就會一直 403。驗簽用的公鑰在
> `https://<團隊名>.cloudflareaccess.com/cdn-cgi/access/certs`，Cloudflare 每六週輪替一次，
> 所以 Worker 那邊的快取只留一小時。

憑證有效 12 小時。它等於「這個房間的入場券」：QR 流出去的後果就是別人也能進那一間，
跟現在把房號告訴別人一樣，關掉房間就結束了。

**副作用**：房號不再是入場憑證，所以**手抄房號進不去**，晚到的人一定要掃 QR
（主控台左下角的房號點一下就會放大 QR）。

#### 設定完之後怎麼確認

從外面（沒登入的機器）打這幾條，對照這張表就知道有沒有真的鎖上：

```bash
for p in ws export whereami close; do
  curl -s -o /dev/null -w "$p %{http_code}\n" "https://<你的網域>/$p/TESTAA"
done
curl -s -o /dev/null -w "host %{http_code}\n" "https://<你的網域>/host"
curl -s -o /dev/null -w "ambient %{http_code}\n" "https://<你的網域>/ambient"
```

| 路徑 | 鎖好的話 | 意思 |
|---|---|---|
| `/ws` `/export` `/whereami` `/close` | **403** `room token required` | 路人開不了 DO |
| `/host`、`/api/room` | **302** → `<團隊>.cloudflareaccess.com` | 只有你換得到憑證 |
| `/client` `/ambient` `/audio` `/voice` `/arts` | **200** | 玩家與背景模式沒被波及 |

⚠️ **`/close` 回 200 就是還沒鎖上**，不管字條顯示什麼。
secret 是即時生效的，補設完不用重新部署，再打一次就會變 403。

### 逃生鈕怎麼運作

`POST /close/<房號>` 直接叫那間的 DO 關房，回一個 JSON 說**關掉之前還有幾條連線**——
所以它同時是「這間到底還活著沒有」的檢查。主控台每開一間就把房號記進
localStorage（`mahou-rooms`，留最近 40 筆），逃生鈕就是把那份清單跑一遍。

沒有 API 可以列出「所有活著的 DO」，所以只能自己記。這也是它的限制：
**只清得掉這台瀏覽器開過的房間**。換一台電腦開的房間要在那台按，或直接
`curl -X POST https://<你的網域>/close/<房號>`。

房號本來就是進得去的憑證（掃 QR 就能加入），所以 `/close` 不另外設密碼——
能關掉一個自己知道房號的房間，比忘記關讓它繼續計費好。

實測：3 條連線（1 主控 + 2 手機）的房間 → `{"closed":true,"live":3}`，三條全部收到
`4000 / remote`；再打一次回 `alreadyEnded:true`；關房後才連進來的當場被踢
（`4000 / room ended`）；房號不合法回 404。

**DO 的費用是按存活時間算的**（128MB × 秒數）。免費方案一天 13,000 GB-s，
一個忘記關的房間撐到 6 小時上限就是 2,765 GB-s——一間就吃掉兩成。
按過「結束房間」或逃生鈕的，連線一清空成本就歸零。

### 背景模式不會開 DO

`/ambient` 完全不碰 DO：它沒有 WebSocket、不開房間，整頁跟歌詞 JSON、相簿清單
都是靜態資源（Worker 根本不會被叫起來）。唯一會進 Worker 的是音檔的
`/audio/*.mp3`（因為要自己回 Range），那條路徑只用 `env.ASSETS`，
碰不到 `env.ROOM`——`worker/index.js` 裡只有
`^/(ws|export|whereami|close)/[A-Za-z0-9]{4,8}$` 這個 pattern 會取得 DO stub。
所以背景模式開一整晚也不會產生 DO 費用。

## 已知限制

- **手感未定案**：滑雪速度、變色龍難度、砸罐子回充與歡樂度都還在調，用 ⚙︎ 手感面板現場決定
- **滑雪跳台的手感已經驗過一輪**：真機 60 秒 18 座跳台、11 連、最高 37.9 m/s。上一版「小彈吃掉跳台」的 bug（60 秒只跳到 1 座）已修，補救窗 0.7 秒
- **陀螺儀雷射筆的漂移**：iOS 的 alpha 角會漂。砸罐子已經用「確定鎖定」＋「補球自動歸零」把它擋掉了；變色龍還是靠「游標回中央」＋觸控板備援，漂多快要真機量
- **名畫已經自己 host**：`public/arts/` 八張 2.6MB，實測 7–19ms 載完，Wikimedia 只當備援。要更新用 `node tools/fetch-arts.mjs`
- **自訂主題的圖片只存在主控那台瀏覽器**（IndexedDB），可以「存成一個檔」搬到別台。有版權的素材請走這條，不要 commit 進來，也不要放上 R2——bucket 私有不代表傳遞私有，遊戲照樣會把圖送到每一支手機
- **iOS 只驗過一部分**：感測器權限與連點防縮放已在 iPhone 上跑過；連點觸發雙擊縮放的修法只在模擬器驗過機制，Safari 本尊要再確認
- **傾斜轉向在劇烈連點下的穩定度**：EMA α=0.16 重低通 ＋ 3.5° 死區，代價是轉向變鈍，真機還要再調
- **匯出的欄位就是能查到的全部**：`lv` 曾經只轉發給主機、沒寫進紀錄檔，害得整份匯出看起來像超加速沒生效。新增欄位時記得 `log()` 與 `toHosts()` 兩邊都要加
- **房間憑證有效 12 小時**，過期之後那一間的 QR 就失效了（重開主控台會拿到新的）。
  同一場家宴用不到 12 小時，但隔天想用昨天的 QR 是不行的
- **逃生鈕只清得掉這台瀏覽器開過的房間**（房號與憑證記在 localStorage）。
  換一台電腦開的房間要在那台按，或 `curl -X POST '<網域>/close/<房號>?t=<憑證>'`
- 遙測存 DO 記憶體，**閒置回收即消失**，測完立刻匯出
- `tShow` 類的顯示延遲含螢幕更新等系統性常數偏差，組間比較有效，絕對值不要拿去跟文獻比
